# Payment identity assets

`bank-melli.svg` is Bank Melli Iran's horizontal logo. It identifies the existing Sadad / `melli_pay` gateway.

Source: https://commons.wikimedia.org/wiki/File:BmiBank_Melli_Iran-hor.svg

Original bank asset referenced by the source: https://baam.bmi.ir/fa/assets/images/logos/bmi/bmi-hor.svg

The image is served locally so displaying a payment choice does not contact a third-party image host.
